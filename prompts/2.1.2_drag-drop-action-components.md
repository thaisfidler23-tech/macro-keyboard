# 2.1.2 Drag-and-Drop Action Components

**Epic**: Visual Macro Editor (RICE: 16.9)  
**Phase**: 2 - Market Differentiation (Q2 2025)  
**Story Points**: 3  
**Priority**: P1 - High  
**Dependencies**: 2.1.1 Visual Macro Editor Interface

---

## 🎯 **Objective & Scope**

Develop a comprehensive library of drag-and-drop action components that represent all macro functionality as visual building blocks. These components form the core of the visual macro editor, enabling users to build complex workflows through intuitive visual composition.

**Business Value**: Enables non-technical users to access the full power of the macro system, directly expanding the addressable market beyond technical users to mainstream productivity users.

---

## 📋 **User Story**

**As a** user creating macros with the visual editor  
**I want** a complete library of drag-and-drop action components  
**So that** I can build any macro functionality visually without needing to understand code syntax or command structures

---

## 🔧 **Technical Requirements**

### **Component Architecture**
- React-based action component framework
- Standardized component interface for consistent behavior
- Dynamic property system for component configuration
- Visual styling system with category-based color coding
- Component validation and error indication system

### **Action Component Categories**

#### **Basic Actions (8 components)**
- **Command Execution**: Run system commands with parameter inputs
- **Key Press**: Single key or key combination with modifier support
- **Text Input**: Type text with variable substitution support
- **Mouse Click**: Click actions with coordinate or element targeting
- **Wait/Delay**: Configurable delay with duration picker
- **Screenshot**: Capture screen areas with file save options
- **Audio Control**: System volume and audio device management
- **Window Management**: Focus, minimize, maximize, close windows

#### **Application Control (6 components)**
- **Launch Application**: Start applications with parameter support
- **Switch Window**: Focus specific windows by title or class
- **Close Application**: Terminate applications gracefully or forcefully
- **Application State**: Check if applications are running
- **Process Management**: Start/stop system processes
- **Service Control**: Manage system services (Windows/Linux/macOS)

#### **File Operations (7 components)**
- **Create File**: Generate files with template content
- **Copy/Move Files**: File system operations with path selection
- **Delete Files**: Safe deletion with confirmation options
- **File Existence Check**: Conditional logic based on file presence
- **Directory Operations**: Create, list, and manage directories
- **File Content**: Read/write file contents with encoding support
- **Archive Operations**: Zip/unzip with compression options

#### **Logic & Flow Control (5 components)**
- **If/Then/Else**: Conditional execution with visual branches
- **Loop**: Repeat actions with counter and condition options
- **Variable Assignment**: Set and modify workflow variables
- **Try/Catch**: Error handling with exception management
- **Parallel Execution**: Run multiple action branches simultaneously

### **Component Properties System**
- Dynamic property panels based on component type
- Type-safe property validation and error indication
- Visual property editors (color pickers, file browsers, dropdowns)
- Variable substitution support in all text properties
- Property templates for common configurations

## ✅ **Acceptance Criteria**

```gherkin
Given I am using the visual macro editor
When I access the action component palette
Then I should see:
  - 26+ action components organized in 4 clear categories
  - Each component with descriptive icons and tooltips
  - Search functionality to quickly find specific actions
  - Filter options to show only components from specific categories
  - Recently used components highlighted for quick access

And when I drag a component onto the canvas
Then the component should:
  - Provide visual feedback during drag operation
  - Snap to connection points on other components
  - Display appropriate input and output connection points
  - Show a property panel for configuration when selected
  - Validate its configuration and show error indicators if invalid

And when I configure component properties
Then I should be able to:
  - Use intuitive editors appropriate for each property type
  - Reference workflow variables in text properties using ${variable} syntax
  - Preview the effect of property changes in real-time
  - Reset properties to default values with a single click
  - Copy property configurations between similar components

And for each component type
Then it should:
  - Generate correct executable code for the macro engine
  - Provide accurate execution time estimates
  - Support all relevant parameters from the underlying action system
  - Include help documentation accessible from the property panel
  - Work consistently across all supported platforms (macOS/Windows/Linux)
```

## 🚀 **Implementation Notes**

### **Component Architecture**
- Use React compound component pattern for consistent structure
- Implement component registry system for easy extension
- Design property system to support custom validators and editors
- Use React Context for component-canvas communication

### **Property System Design**
- Type-safe property definitions with runtime validation
- Support for complex property types (arrays, objects, references)
- Variable substitution system with syntax highlighting
- Property templates for common configuration patterns

### **Performance Considerations**
- Lazy loading of component definitions to reduce initial bundle size
- Virtualization for large component palettes
- Optimized drag-and-drop with RAF-based animation
- Memoization of property panels to prevent unnecessary re-renders

### **Extensibility Planning**
- Plugin-compatible component interface for third-party additions
- Component marketplace integration points
- Version management for component schema evolution
- Import/export system for custom component libraries

This comprehensive component library forms the foundation that enables non-technical users to access the full power of the macro system through intuitive visual composition, directly addressing the strategic goal of expanding beyond technical users to capture the broader productivity software market.
