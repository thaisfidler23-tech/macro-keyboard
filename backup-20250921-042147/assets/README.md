# Icon Placeholder

This directory should contain application icons:

- `icon.png` - Main application icon for macOS and Linux (512x512 px recommended)
- `icon.ico` - Windows application icon (multiple sizes: 16x16, 32x32, 48x48, 256x256)

## Creating Icons

You can create your own icons or use online tools to generate multi-format icons from a source image.

### Recommended Tools:
- [IconGenerator](https://www.icongenerator.net/)
- [Favicon.io](https://favicon.io/)
- Adobe Illustrator/Photoshop for custom designs

### Icon Requirements:
- **PNG format** for macOS/Linux: 512x512px minimum
- **ICO format** for Windows: Include 16x16, 32x32, 48x48, and 256x256px sizes
- Use a design that works well at small sizes (16x16px)
- Consider using keyboard/macro/automation themed imagery

## Temporary Placeholder

Until custom icons are created, the application will use default system icons or may display placeholder graphics.
